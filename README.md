# Pokémon Battle Arena

A 1,025-Pokémon battle arena game (Gen I–IX) with Mega Evolution, Gigantamax, Dynamax, Z-Moves, Terastallization, and a 10-round championship trial.

Play it here: https://haydenyung0726.github.io/pokemon-battle-arena/

## Versions

Every game update is pushed here as its own commit, so you can always go back:

- **See all versions:** open the repo on GitHub and click `Commits`
- **Restore an old version:** open the commit you want, click `Browse files`, or use `git revert` / `git checkout <commit> -- index.html` locally
- **Current build:** `index.html` (self-contained, works offline)

## Latest features

- 1,025 Pokémon (Gen I–IX) + 58 regional forms + 26 Legends: Z-A Mega Evolutions
- Randomized evolvable starter, locked until Round 5
- Ally Surge from Round 7 (+75% HP, 1.75x attack)
- Terastallization, Dynamax/Gigantamax, Mega Evolution, Z-Moves, Max Moves
- 8 wins out of 10 rounds to take the championship
